# Team NAK Demos

Interactive demos built with Claude Sonnet 5.5. Each one is a single self-contained HTML page, with no build step and no dependencies.

**[▶ Open the live demos](https://nadiraliofficial.github.io/team-nak-demos/)**

## Demos

### Live solar system
Real orbital elements and the real date. Speed the clock from live time up to a year per second.

[![Live solar system](assets/preview-solar-system-live.gif)](https://nadiraliofficial.github.io/team-nak-demos/solar-system-live.html)

### Trading bot in action
A simulated EMA 9/21 crossover bot on a live-moving chart, with a trade log and simulated account equity.

[![Trading bot in action](assets/preview-trading-bot-demo.gif)](https://nadiraliofficial.github.io/team-nak-demos/trading-bot-demo.html)

### How an IBKR bot works
An animated walkthrough from signal to filled order, including risk checks and a blocked-order case.

[![How an IBKR bot works](assets/preview-ibkr-bot-flow.gif)](https://nadiraliofficial.github.io/team-nak-demos/ibkr-bot-flow.html)

### Sunset ride
An animated cyclist scene.

[![Sunset ride](assets/preview-cyclist.gif)](https://nadiraliofficial.github.io/team-nak-demos/cyclist.html)

### Solar system v1
The first, simpler version of the solar system.

[![Solar system v1](assets/preview-solar-system.gif)](https://nadiraliofficial.github.io/team-nak-demos/solar-system.html)

## Run locally

Open `index.html` in a browser.
